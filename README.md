# MT1-LABEXAM - Vehicle Management

## Setup
```bash
npm install
```

## Run
```bash
node httpServer.js     # http://localhost:3000
node expressApp.js     # http://localhost:4000
```

## Part A routes (3000)
/ , /vehicles , /about , /info , POST /add-vehicle

## Part B routes (4000)
GET /vehicles, GET /vehicles/:id, POST /vehicles, PUT /vehicles/:id, DELETE /vehicles/:id
